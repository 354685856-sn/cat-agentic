下载后就是工作区

启动后直接进入本地桌面界面，不需要把项目上传到远端控制台。模型服务商由客户自己配置。

  • ✓项目文件和会话记录保存在本机。
  • ✓API 密钥保留在环境变量中，不写入项目配置。
  • ✓终端命令默认需要人工确认。

⌘ macOS 首次启动

当前 DMG 是客户测试用开发预览版，尚未完成 Apple 签名与公证。

  1. 打开 DMG，把 Cat Agentic 拖入“应用程序”。
  2. 第一次启动时右键应用图标，选择“打开”。
  3. 等待本地环境准备完成，浏览器会自动打开桌面工作区。
  4. 进入“设置 → 服务商”，填写模型与 API 密钥环境变量名。
如果 macOS 拦截启动，请在“系统设置 → 隐私与安全性”中确认打开。不要关闭系统安全功能。

›_ Windows / Linux / 高级用户

当前已发布包名仍是 x-agentic-workflow；安装后可以使用兼容命令 xaw。

pipx install x-agentic-workflow
xaw desktop
  • 系统：macOS 12+、Windows 10+ 或主流 Linux。
  • 运行时：Python 3.10+，建议使用 pipx。
  • 首次启动：需要网络安装本地依赖。
  • 模型：使用客户自己的 Anthropic 或 OpenAI 兼容 API。
